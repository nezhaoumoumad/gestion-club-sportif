# Application Web de Gestion de Club Sportif

 Plateforme web permettant la gestion complète d'une salle de sport (membres, coachs, plannings et abonnements).

## Technologies utilisées
* **Frontend :** React, Tailwind CSS, Bootstrap
* **Backend :** Laravel (PHP)
* **Base de données :** MySQL

## Fonctionnalités principales
* Gestion des membres et des coachs
* Suivi des abonnements et paiements
* Programmation des séances et créneaux horaires
* Tableau de bord administrateur
